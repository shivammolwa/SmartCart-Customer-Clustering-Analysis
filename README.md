# SmartCart - Customer Clustering Analysis

An unsupervised machine learning project that creates customer clusters based on different features such as income, education, marital status, number of children, and other customer characteristics.

# 📌 Project Overview

The goal of this project is to segment customers into different groups based on their characteristics and purchasing-related information.

The project covers the following Machine Learning workflow:

- Data cleaning
- Exploratory Data Analysis (EDA)
- Feature preprocessing
- Categorical variable encoding
- Feature scaling
- Data visualization
- Customer clustering
- Cluster analysis

# 📂 Dataset

The dataset contains customer information such as:

- Education
- Income
- Marital Status
- Number of children
- Number of teenagers
- Other customer-related features

The dataset is not included in this repository.

# 🔧 Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

# ⚙️ Workflow

1. Load the dataset
2. Understand the data
3. Handle missing values
4. Perform Exploratory Data Analysis
5. Encode categorical features
6. Scale numerical features
7. Perform data visualization
8. Apply clustering algorithms
9. Analyze the resulting customer segments
